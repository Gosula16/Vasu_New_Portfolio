# Vasu_New_Portfolio

Premium student developer portfolio — Next.js (App Router), Tailwind CSS, Framer Motion, GSAP, React Three Fiber, TypeScript.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open [http://localhost:3000](http://localhost:3000) for local development.

## Deploy

Configure `siteConfig.url` in `lib/data.ts`, add `public/resume.pdf` if you use the résumé download link, then deploy (e.g. Vercel).
